01 · How it works

From project to video in three moves

01

Claude plans the demo

It reads your project and suggests a short story: 3 to 5 moments, under 20 seconds. Say yes or ask for changes, in plain words.

02

You pick the look

Demo Kitchen opens in your browser with your product inside. Choose one of eight styles and switch on extras like captions or an end card.

03

Export and share

An MP4 for LinkedIn, X or YouTube, or a GIF for Substack or a README. Want something specific? Just tell Claude.

02 · Install

Make one for your project

You need a Mac and the Claude desktop app with Claude Code. You never have to open the Terminal: Claude does the technical parts and asks before it runs anything.

  1. 1

    Ask Claude to install it

    Open the Claude app, go to Code, and paste this message:

    Please install the Demo Kitchen plugin for me. It's in the plugin marketplace at github.com/{{REPO}} (marketplace "demo-kitchen-tools", plugin "demo-kitchen"). Install it for my user so it works in every project, then tell me when it's ready.

    Claude will ask to run a couple of commands. Click Allow. When it says it's ready, start a new session.

    Please install the Demo Kitchen plugin for me…
    Claude wants to run a command
    DenyAllow
  2. 2

    Open your project

    Start a new session and choose the folder of the project you want to show off, with the folder button next to the prompt box. It's the same folder you built it in.

    Just want to look around first? Any folder works for the practice run in step 3.

    Describe a task…
    Local ▾ my-habit-tracker ▾
  3. 3

    Type /demo-video

    Claude takes it from there: it plans the demo with you, builds the screens and opens Demo Kitchen in your browser.

    /demo-video

    Type /demo-video sample instead to practice on a ready-made app first. It takes about a minute.

03 · The first time

What to expect

Tools get set up

If your Mac is missing anything (Node, a video encoder, Chrome), Claude downloads private copies into one folder. About 2 minutes, once. No passwords.

Claude asks first

You'll see Allow buttons along the way. Clicking Allow is how you say yes. Nothing runs without it.

A quick welcome

When Demo Kitchen opens, a short guide shows you around: pick a style, add extras, export.

Your video, saved

It lands in a demo/out folder in your project. Ask Claude “open the folder” and it will.

04 · Questions

Good to know

Does it upload my project anywhere?

No. Demo Kitchen runs on your Mac, and the video is made on your Mac. Claude reads your project the same way it does when you build with it.

Does it work on Windows?

Not yet. It's Mac only for now.

My product is a Figma plugin, a mobile app or behind a login. Can it still make a demo?

Yes. When your product can't be recorded cleanly, Claude rebuilds the screens as a clean scene instead of filming them. That's how the Figma plugin demo in the Design with AI article was made.

How do I change something small, like a caption or the cursor size?

Ask Claude in the same chat: “change the second caption to …”, “make the cursor bigger”, “slow down when the dashboard appears”. The preview in your browser updates by itself.

Where's my video?

In the demo/out folder of your project. The export window also has a Show in Finder button.

How do I remove it?

Ask Claude: “uninstall the Demo Kitchen plugin and delete ~/.demo-kitchen”.
